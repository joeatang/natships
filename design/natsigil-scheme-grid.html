1. Reference vs proposed rendering

NAT logo (reference)
NAT SIGIL eye (proposed)
Design intent — the NAT SIGIL eye is a stylized adaptation of the NAT logo, sized to fit the UNATOM's crown position (radius 60 in the 1024×1024 canvas). Six outer nodes in hexagonal formation around one central orange node, with lines connecting center→node and node→node forming the hex ring. Above sits a subtle halo arc (matching the existing halo and oracle eye variants) so it reads as sacred, not just technical.

Palette rule — outer nodes + lines use the active scheme's border color for guaranteed visibility on every shell. The central core is always true NAT orange (#F07E1B) regardless of scheme — that's the identity override. The disc uses the scheme's darkest ink for depth.

3. Spec (locked pending your review)

  • Type — third-eye override (not a 17th slot). When trigger fires, third-eye becomes natSigil regardless of nonce_byte3.
  • Trigger — height contains "111" (19 blocks: 111, 1110–1119, 2111..9111) OR merkleroot[0] === nonce_byte0 (~39 additional blocks)
  • Expected count — ~55 pieces across 10,080 (~0.55% — rarer than crosshair which is 1/16 = 6.25%)
  • Palette — nodes + connectors use sch.border normally, but flip to white when sch.border is dark (luminance < 0.45) so they always pop on the dark disc. Core is always #F07E1B; disc uses BASE.pupil.
  • Halo — thin arc above in sch.a (matches halo/oracle family)
  • Composability — stacks with flameborn (flame ring wraps hex), blazedBluntie, Hi element badge
  • Guards — if base thirdEye was sealed, override still wins (natSigil takes precedence)
